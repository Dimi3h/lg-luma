Luma 3.0 marks this as Dimi3h's personal fork of ecklf/lg-luma, with its own interface and feature set (see the readme). Settings removed in this release (Text size, Night wallpaper, wallpaper Rotation, the Gradient toggle and Reduced motion) no longer exist; existing preference files keep loading. The app ID is unchanged (`com.ecklf.luma`), so it updates the installed app in place.
