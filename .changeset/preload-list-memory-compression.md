Choose which apps to preload: a Preload / Stop preloading entry in each app's menu and a list in Settings › General › Preload apps (with the most used web apps still chosen automatically while the list is empty). Native apps can be preloaded too; apps LG keeps preloaded itself are left to LG, memory is judged by LG's own memory manager, and an app that comes to the front within 90 s of its hidden start is closed and shown as unable to start hidden. New Settings › System › Memory compression (on by default with the Home takeover) adds a compressed swap in RAM on the TV's unused zram device at every cold boot.
