Choose which apps to preload: a Preload / Stop preloading entry in each app's menu and a list in Settings › General › Preload apps (with the most used web apps still chosen automatically while the list is empty). Native apps can be preloaded too; apps LG already preloads itself are left to LG, and an app that cannot start hidden is shown as such. New Settings › System › Memory compression (on by default with the Home takeover) adds a compressed swap in RAM on the TV's unused zram device at every cold boot.
